Rock Paper Scissors Game

Overview

This is a simple command-line Rock Paper Scissors game built with Python. The player chooses Rock, Paper, or Scissors, and the computer randomly selects one of the three options.

The program compares both choices and determines whether the player wins, loses, or draws.

Features

Allows the player to choose Rock, Paper, or Scissors.

Generates a random computer choice.

Displays the player's selection.

Displays the computer's selection.

Determines the winner based on the game rules.

Announces whether the player wins, loses, or draws.

Technologies Used

Python 3

random module

Lists

Variables

Conditional statements

User input

F-strings

How to Play

Run the Python program.

Enter 0 for Rock, 1 for Paper, or 2 for Scissors.

The computer randomly selects its choice.

The program displays both choices.

The result is displayed.

Game Rules

Rock beats Scissors.

Scissors beats Paper.

Paper beats Rock.

Matching choices result in a draw.
